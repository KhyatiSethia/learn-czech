# Declension patterns

Czech nouns follow patterns (paradigms). Learn one model word per pattern, and every other noun of that kind works the same way. The tables show the model words; endings are in bold and red.

Nouns are **hard** when the stem ends in a hard consonant (*pán*, *hrad*, *žena*, *město*) and **soft** when it ends in a soft one (*muž*, *stroj*, *růže*, *moře*). Hard and soft patterns differ mostly in the vowel of the ending.

## Masculine animate

### *pán* (gentleman), hard

| Case | Singular | Plural |
| --- | --- | --- |
| Nominative | pán | pán**i** |
| Genitive | pán**a** | pán**ů** |
| Dative | pán**ovi** / pán**u** | pán**ům** |
| Accusative | pán**a** | pán**y** |
| Vocative | pan**e** | pán**i** |
| Locative | pán**ovi** / pán**u** | pán**ech** |
| Instrumental | pán**em** | pán**y** |

## Things the tables do not show

### Consonant changes before -e, -ě and -i

Before the dative and locative ending of feminine nouns and before some plural endings, some consonants change:

| Change | Example |
| --- | --- |
| k → c | *matka → mat**ce*** |
| h → z | *kniha → kni**ze***, *Praha → Pra**ze*** |
| ch → š | *střecha (roof) → stře**še*** |
| r → ř | *sestra → sest**ře*** |

### -ě or -e?

After **d, t, n, b, p, v, f, m** the ending is spelled *-ě*: *žen**ě***, *Ostrav**ě***, *měst**ě***. After other consonants it is *-e*: *škol**e***, *Praze* (after the change), *hor**e***. This is the same spelling rule as in [sounds and spelling](/grammar/pronunciation).

### The vowel that appears and disappears

Some nouns lose a vowel when an ending is added, or gain one in the genitive plural:

| Nominative | Genitive | Meaning |
| --- | --- | --- |
| pes | psa | dog |
| den | dne | day |
| otec | otce | father |
| matka | matek (gen. plural) | mother |
| sestra | sester (gen. plural) | sister |

### Genitive plural of feminine and neuter

Hard feminine and neuter nouns often have **no ending** in the genitive plural: *žena → žen*, *škola → škol*, *město → měst*. A vowel is inserted when the result would be unpronounceable: *sestra → sester*, *matka → matek*.

### Two possible endings

You will meet two endings in some cells: *pánovi / pánu*, *hradu / hradě*. Both are standard. When in doubt use the first one in the table; it is always safe.

## Find the pattern

| Your word | Pattern | Hint |
| --- | --- | --- |
| a living male being, hard consonant | *pán* | *kamarád*, *student* |
| a living male being, soft consonant (*-č, -ž, -š, -ř, -c, -j*) | *muž* | *lékař* (doctor), *cizinec* (foreigner) |
| a thing, masculine | *hrad* or *stroj* | hard or soft stem |
| feminine in *-a* | *žena* | *škola*, *kniha* |
| feminine in *-e* | *růže* | *ulice* (street), *židle* (chair) |
| feminine in a consonant | *kost* | *věc*, *noc* |
| neuter in *-o* | *město* | *okno*, *auto* |
| neuter in *-e* | *moře* | *pole* (field), *slunce* (sun) |
