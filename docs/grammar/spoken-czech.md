# Spoken Czech (obecná čeština)

Czech has two layers. **Standard Czech** (*spisovná čeština*) is what textbooks, exams, newspapers and official letters use. **Common Czech** (*obecná čeština*) is what many people speak in everyday life, especially in Bohemia. It is not slang. It is a regular system of sound changes, and once you know them, fast speech becomes much easier to follow. Regional speech in Moravia and Silesia differs again in vocabulary and some endings.

**You don't need to speak it.** Standard Czech is understood everywhere. It can sound a bit bookish, but nobody minds. The goal of this page is to help you **understand** what you hear.

## The main changes

| Rule | Standard | Spoken |
| --- | --- | --- |
| **-ý** becomes **-ej** | dobrý, malý, nový | dobrej, malej, novej |
| **-é** becomes **-ý** (neuter and plural endings) | dobré auto, dobré ženy | dobrý auto, dobrý ženy |
| a **v-** is added before **o-** | okno, on, opravdu | vokno, von, vopravdu |
| **ý** in the stem becomes **ej** | být, výlet | bejt, vejlet |
| **é** becomes **í** in some words | mléko, polévka | mlíko, polívka |
| plural instrumental **-ama** | s kamarády | s kamarádama |
| **bychom** becomes **bysme** | šli bychom | šli bysme |
| **ano** becomes **jo** | ano | jo |

## Forms of *být*

| | Standard | Spoken |
| --- | --- | --- |
| já | jsem | sem |
| ty | jsi | seš |
| my | jsme | sme |
| vy | jste | ste |

*Seš unavenej?* = *Jsi unavený?* Are you tired?

The first person is easy to confuse with *sem* (here). Context makes it clear: *Sem unavenej* means "I'm tired", while *Pojď sem* means "Come here".

## Words you will hear all the time

| Word | Meaning |
| --- | --- |
| *no* | well, yeah (a filler word) |
| *hele* | look, listen |
| *jako* | like (a filler word) |
| *prostě* | simply, just |
| *vlastně* | actually |
| *asi* | probably |
| *fakt* | really |
| *jasně* | sure, of course |
| *bezva*, *fajn* | great, fine |
| *kafe* | coffee (instead of *káva*) |
| *čau*, *nashle* | bye |
| *že jo?* | right? (a tag question, informal) |

## Standard or spoken: what to use when

| Situation | Use |
| --- | --- |
| Writing an e-mail to an office, a teacher or a landlord | standard |
| Exams and language courses | standard |
| Texting friends | mostly spoken |
| Talking to anyone in person | either. Mixing is normal. |

Learners often find that their textbook Czech works well when speaking, and that *listening* is the hard part. When you hear something unfamiliar, try undoing the rules above: *vokno* → *okno*, *dobrej* → *dobrý*, *seš* → *jsi*.

## Practise

Try adding a few spoken forms to your own deck so you start to recognise them. For example, put the spoken version in the question and the standard form in the answer: *Seš unavenej? | Jsi unavený?*
