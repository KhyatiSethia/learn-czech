# Comparing things

## Comparative adjectives: *-ější*, *-ejší* and short forms

The comparative ("bigger", "more interesting") ends in **-í** and doesn't change for gender in the nominative: *větší dům, větší škola, větší město*. It then declines like [*moderní*](/grammar/adjectives).

### Regular: add *-ější* or *-ejší*

Add the suffix to the stem. The spelling depends on the last consonant:

| Stem ends in | Suffix | Examples |
| --- | --- | --- |
| **d, t, n, b, p, m, v, f** | **-ější** | nový → nov**ější**, levný → levn**ější**, zajímavý → zajímav**ější**, moderní → modern**ější** |
| other consonants | **-ejší** | rychlý → rychl**ejší**, pomalý → pomal**ejší**, chytrý → chytř**ejší** |

### Short forms with *-ší* and *-čí*

Many common adjectives drop the ending and take **-ší** or **-čí** instead:

| Adjective | Comparative | Meaning |
| --- | --- | --- |
| starý | star**ší** | older |
| mladý | mlad**ší** | younger |
| bohatý | bohat**ší** | richer |
| čistý | čist**ší** | cleaner |
| krátký | krat**ší** | shorter |
| hluboký | hlub**ší** | deeper |
| široký | šir**ší** | wider |
| těžký | těž**ší** | heavier, harder |
| hezký | hez**čí** | prettier |
| lehký | leh**čí** | lighter, easier |

### Irregular comparatives

| Adjective | Comparative |
| --- | --- |
| dobrý good | **lepší** better |
| špatný bad | **horší** worse |
| velký big | **větší** bigger |
| malý small | **menší** smaller |
| dlouhý long | **delší** longer |
| vysoký tall | **vyšší** taller |
| nízký low | **nižší** lower |
| úzký narrow | **užší** narrower |
| blízký close | **bližší** closer |
| drahý expensive | **dražší** more expensive |

## "Than": *než*

*Než* is followed by the same case as the first item, which is usually the nominative:

- *Praha je větší než Brno.* Prague is bigger than Brno.
- *Ona je starší než já.* She is older than me.
- *Káva je dražší než čaj.* Coffee is more expensive than tea.

Measure the difference with **o** + accusative: *Je o dva roky starší.* (She's two years older.) *O hodně větší.* (Much bigger.)

## "As … as"

- *Je stejně starý jako já.* He's the same age as me.
- *Je tak vysoký jako ty.* He's as tall as you.
- *Nejsem tak rychlý jako ty.* I'm not as fast as you.

## Superlative: *nej-* + comparative

Put **nej-** in front of the comparative: *nejlepší* (best), *nejhorší*, *nejstarší*, *nejlevnější*, *nejzajímavější*.

- *To je nejlepší kavárna ve městě.* That's the best café in town.
- *Je nejmladší z nás.* She's the youngest of us.

*Ve městě* (in the town) uses the locative. *Z nás* (of us) uses the genitive.

## Comparing adverbs

An adverb can also be compared. Regular ones end in **-ěji** or **-eji**:

| Adverb | Comparative | Meaning |
| --- | --- | --- |
| rychle | rychle**ji** | faster |
| pomalu | pomale**ji** | more slowly |
| hezky | hezče**ji** | more nicely |
| brzy | dříve / dřív | earlier |
| dlouho | déle / dýl | longer |
| dobře | lépe / líp | better |
| špatně | hůře / hůř | worse |
| hodně | více / víc | more |
| málo | méně / míň | less |

The short spoken forms (*líp, hůř, víc, míň, dřív, dýl*) are everyday speech. *Můžete mluvit pomaleji?* (Can you speak more slowly?) is a sentence you'll use a lot.

*Víc* and *míň* take a genitive: *víc času* (more time), *míň peněz* (less money).

## "The more … the more": *čím … tím*

- *Čím víc se učím, tím víc rozumím.* The more I study, the more I understand.
- *Čím dřív, tím líp.* The sooner the better.
