# Numbers

## Cardinal numbers

| 0–10 | 11–19 | Tens |
| --- | --- | --- |
| 0 nula | 11 jedenáct | 20 dvacet |
| 1 jeden, jedna, jedno | 12 dvanáct | 30 třicet |
| 2 dva, dvě | 13 třináct | 40 čtyřicet |
| 3 tři | 14 čtrnáct | 50 padesát |
| 4 čtyři | 15 patnáct | 60 šedesát |
| 5 pět | 16 šestnáct | 70 sedmdesát |
| 6 šest | 17 sedmnáct | 80 osmdesát |
| 7 sedm | 18 osmnáct | 90 devadesát |
| 8 osm | 19 devatenáct | 100 sto |
| 9 devět | | 1000 tisíc |
| 10 deset | | |

Only **1** and **2** change for gender: *jeden muž*, *jedna žena*, *jedno dítě*; *dva muži*, *dvě ženy*, *dvě děti*.

### Compound numbers

Say the biggest part first: *dvacet jedna* (21), *sto padesát pět* (155), *dva tisíce dvacet šest* (2026). From 21 to 99 you may also put the units first: *jedenadvacet* (21), *pětačtyřicet* (45).

Hundreds change with the multiplier: *sto*, *dvě stě*, *tři sta*, *čtyři sta*, *pět set*. Thousands too: *tisíc*, *dva tisíce*, *pět tisíc*.

## What number does to the noun

| Number | The noun is in | Example |
| --- | --- | --- |
| 1 | the singular | *jedna koruna* |
| 2, 3, 4 | the nominative plural | *dvě koruny*, *tři piva*, *čtyři domy* |
| 5 and up | the **genitive** plural | *pět korun*, *šest piv*, *dvacet domů* |

This is also how you read prices: *Kolik to stojí? To stojí sto dvacet korun.* (It costs 120 crowns.)

## Ordinal numbers

They are adjectives. Most decline like *nový*; *třetí* declines like the soft *cizí*.

| Number | Ordinal | Number | Ordinal |
| --- | --- | --- | --- |
| 1st | první | 6th | šestý |
| 2nd | druhý | 7th | sedmý |
| 3rd | třetí | 8th | osmý |
| 4th | čtvrtý | 9th | devátý |
| 5th | pátý | 10th | desátý |

## Telling the time

*Kolik je hodin?* What time is it?

| Time | Czech |
| --- | --- |
| 1:00 | *Je jedna hodina.* |
| 2:00 | *Jsou dvě hodiny.* |
| 5:00 | *Je pět hodin.* |
| 5:15 | *Je čtvrt na šest.* (a quarter *toward* six) |
| 5:30 | *Je půl šesté.* (half *toward* the sixth hour) |
| 5:45 | *Je tři čtvrtě na šest.* |

Czech counts *toward* the next hour. *Půl šesté* means "half of the sixth hour", which is 5:30. So *půl druhé* is **1:30**, not 2:30. At a particular time: *v pět hodin* (at five o'clock), *v půl třetí* (at 2:30).

## Days and months

| Days | Months |
| --- | --- |
| pondělí, úterý, středa | leden, únor, březen |
| čtvrtek, pátek | duben, květen, červen |
| sobota, neděle | červenec, srpen, září |
| | říjen, listopad, prosinec |

*V pondělí* (on Monday), *ve středu* (on Wednesday), *v sobotu* (on Saturday). *V lednu* (in January).
