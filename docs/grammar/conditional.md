# Conditional: "would" and "if"

The conditional says what would happen, or what you would like. It is formed from the **l-participle** (see [past tense](/grammar/verbs-past-future)) plus a short form of *být*: **bych, bys, by, bychom, byste, by**.

| | Masculine | Feminine |
| --- | --- | --- |
| já | dělal **bych** | dělala **bych** |
| ty | dělal **bys** | dělala **bys** |
| on, ona, ono | dělal **by** | dělala **by** (neuter: dělalo **by**) |
| my | dělali **bychom** | dělaly **bychom** |
| vy | dělali **byste** | dělaly **byste** |
| oni | dělali **by** | dělaly **by** (neuter: dělala **by**) |

Do **not** add *jsem* to these. You say *dělal bych*, not ~~*dělal jsem bych*~~.

The participle still agrees with the subject in gender and number, so a woman says *Chtěla bych…* and a man says *Chtěl bych…*. When one person is addressed politely, use the singular participle with the plural *byste*: *Mohl byste mi pomoct?* (to a man), *Mohla byste mi pomoct?* (to a woman).

## Polite requests

This is where you will use the conditional most.

| Czech | Meaning |
| --- | --- |
| *Chtěl bych / Chtěla bych…* | I would like… |
| *Rád bych / Ráda bych…* | I would gladly… |
| *Dal bych si kávu.* | I'll have a coffee. |
| *Mohl byste mi pomoct?* | Could you help me? |
| *Mohla bys mi to říct?* | Could you tell me? (informal) |
| *Měl bys jít domů.* | You should go home. |
| *Šel bych do kina.* | I'd go to the cinema. |
| *Co bys dělal?* | What would you do? |

*Rád* changes with the speaker: *rád* (m.), *ráda* (f.), *rádi* (plural).

## "If" with *kdyby*

*Kdyby* is *když* + *by*, and it takes the same personal forms: **kdybych, kdybys, kdyby, kdybychom, kdybyste, kdyby**.

Czech uses the conditional in **both** halves, where English only uses it in the main clause:

> *Kdybych měl čas, šel bych do kina.*
> If I had time, I would go to the cinema.

> *Kdybys chtěl, mohli bychom jít spolu.*
> If you wanted, we could go together.

> *Co bys dělala, kdybys vyhrála?*
> What would you do if you won?

### Real conditions don't use it

If the situation is genuinely possible, use *jestli* or *pokud* with the normal tenses:

*Jestli bude pršet, zůstanu doma.* If it rains, I'll stay at home.

*Pokud máte čas, zavolejte mi.* If you have time, call me.

### The "past" conditional

A past form exists (*kdybych to byl věděl, byl bych přišel*), but it sounds formal or literary. In normal speech people just use the plain conditional: *Kdybych to věděl, přišel bych.* (If I had known, I would have come.)

## *Aby*: purpose and "want someone to"

*Aby* is *a* + *by*, with the same endings: **abych, abys, aby, abychom, abyste, aby**. It introduces a purpose, or a wish about someone else's action.

- *Učím se česky, abych rozuměl lidem.* I'm learning Czech so that I understand people.
- *Chci, abys přišel.* I want you to come.
- *Řekla mi, abych počkal.* She told me to wait.

If the subject stays the same, use the infinitive: *Chci přijít.* But if the subject changes, you need *aby*.

## Where *bych* goes

*Bych, bys, by…* are clitics, so they sit in second position (see [word order](/grammar/word-order)): *Dnes bych šel domů.* *Šel bych dnes domů.* They never stand first in the clause.
