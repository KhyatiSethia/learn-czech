# Useful phrases

Phrases for the situations you'll meet in a day. *(f.)* and *(m.)* show the form a woman or a man says. *(formal)* is for strangers, older people and shops; *(informal)* is for friends and family.

## *Ty* or *vy*?

Czech has two ways of saying "you". Use **vy** (*Jak se máte?*) with strangers, shop staff, officials, and people clearly older than you. Use **ty** (*Jak se máš?*) with friends, family, children and colleagues who offer it. The offer is called *tykání*, and it is usually made by the older or higher-ranking person. If you aren't sure, start with *vy*.

| Czech | Meaning |
| --- | --- |
| *Dobrý den.* | Hello, good day (formal) |
| *Dobré ráno.* | Good morning |
| *Dobrý večer.* | Good evening |
| *Dobrou noc.* | Good night |
| *Ahoj.* / *Čau.* | Hi, bye (informal) |
| *Na shledanou.* | Goodbye (formal) |
| *Hezký den!* | Have a nice day! |
| *Měj se hezky!* | Take care! (informal) |

| *Prosím.* | Please. / You're welcome. / Here you are. |
| *Děkuju.* / *Děkuji.* | Thank you |
| *Díky.* | Thanks (informal) |
| *Není zač.* | You're welcome |
| *Promiňte.* | Excuse me, sorry (formal) |
| *Promiň.* | Sorry (informal) |

## Introducing yourself

| Czech | Meaning |
| --- | --- |
| *Jmenuju se Anna.* | My name is Anna. |
| *Jak se jmenujete?* | What's your name? (formal) |
| *Těší mě.* | Nice to meet you. |
| *Jsem z Anglie.* | I'm from England. |
| *Odkud jste?* | Where are you from? (formal) |
| *Bydlím v Praze.* | I live in Prague. |
| *Jak se máš?* / *Jak se máte?* | How are you? |
| *Mám se dobře.* | I'm fine. |
| *Ujde to.* | It's so-so. |

## When you don't understand

| Czech | Meaning |
| --- | --- |
| *Nerozumím.* | I don't understand. |
| *Mluvím jen trochu česky.* | I only speak a little Czech. |
| *Mluvíte anglicky?* | Do you speak English? |
| *Můžete to zopakovat?* | Could you repeat that? |
| *Můžete mluvit pomaleji?* | Could you speak more slowly? |
| *Co to znamená?* | What does that mean? |
| *Jak se to řekne česky?* | How do you say that in Czech? |
| *Jak se to píše?* | How is that written? |
| *Jak se to vyslovuje?* | How is that pronounced? |

## Getting around

| Czech | Meaning |
| --- | --- |
| *Kde je nádraží?* | Where is the station? |
| *Jak se dostanu do centra?* | How do I get to the centre? |
| *Je to daleko?* | Is it far? |
| *Je to blízko.* | It's near. |

## Time

| Czech | Meaning |
| --- | --- |
| *Kolik je hodin?* | What time is it? |
| *Je půl třetí.* | It's half past two (2:30). |
| *Dnes, zítra, včera* | today, tomorrow, yesterday |
| *V pondělí, ve středu, v pátek* | on Monday, on Wednesday, on Friday |

## Feelings and health

Many Czech phrases use the **dative** for how you feel, where English uses "I am":

| Czech | Meaning |
| --- | --- |
| *Je mi zima.* / *Je mi teplo.* | I'm cold. / I'm warm. |
| *Je mi špatně.* | I feel sick. |
| *Mám hlad.* / *Mám žízeň.* | I'm hungry. / I'm thirsty. |
| *Jsem unavený.* (m.) / *Jsem unavená.* (f.) | I'm tired. |
| *Bolí mě hlava.* | I have a headache. |
| *Potřebuju lékaře.* | I need a doctor. |
| *Líbí se mi to.* | I like it. |
| *Baví mě to.* | It's fun, I enjoy it. |
